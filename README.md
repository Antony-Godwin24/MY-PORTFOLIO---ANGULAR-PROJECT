## ☁️ Deploying to Vercel (Step-by-Step)

This repository includes a pre-configured [`vercel.json`](./vercel.json) optimized for Angular SPAs.

### Method A: Deploy via Vercel Web Dashboard (Recommended)

1. Log in to [Vercel](https://vercel.com).
2. Click **Add New...** → **Project**.
3. Import your GitHub repository: `Antony-Godwin24/MY-PORTFOLIO---ANGULAR-PROJECT`.
4. In the Project Configuration:
   - **Framework Preset**: Angular *(automatically detected)*
   - **Build Command**: `npm run build` *(or `ng build`)*
   - **Output Directory**: `dist/resume-using-angular/browser`
5. Click **Deploy**. Vercel will build and assign your live domain (e.g. `my-portfolio-angular-project.vercel.app`)!

### Method B: Deploy via Vercel CLI

```bash
npm install -g vercel
vercel login
vercel --prod
```
